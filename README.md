# Vedant Chauhan — Personal Portfolio

A responsive React and Vite portfolio with dedicated Academics, Projects, and
SafeSphere AR case-study pages.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

The **Deploy portfolio to GitHub Pages** workflow deploys when changes are
pushed to `main`, or when started manually from the repository's Actions tab.
Enable GitHub Pages in repository settings and select **GitHub Actions** as
the deployment source if it is not already enabled. The workflow builds the
Vite app with the repository path and publishes an SPA fallback for direct
page links.

The published URL will be:

`https://vedant403.github.io/vedantchuahanportfolio/`
